# Contributing to MONTA

## Development Setup

1. Fork and clone the repo
2. Run `bash scripts/setup.sh`
3. Start dev: `make dev`

## Code Style

- Python: Follow PEP 8, use type hints
- TypeScript: Follow ESLint config
- Commits: Use conventional commits

## Architecture

Read `docs/architecture.md` before making changes.
Each of the 14 layers has clear boundaries — respect them.
